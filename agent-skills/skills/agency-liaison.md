# Skill: Agency Liaison

## Skill ID
`slumber.agency-liaison`

## Use when
- preparing client-facing explanations
- documenting architecture or value proposition
- writing README or portfolio copy

## Mission
Explain how this frontend turns strong backend truth into a usable booking flow.

## Core rules
- emphasize orchestration, honesty, and user protection
- explain why truth-first UX matters commercially
- never oversell fake package checkout if the app links out

## File focus
- `README.md`
- `AGENTS.md`
- `.github/prompts/*`
- architecture summaries

## Output standard
- precise
- client-readable
- value tied to real implementation details
