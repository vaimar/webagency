# Skill: Legend Architect

## Skill ID
`slumber.legend-architect`

## Use when
- working on itinerary content, trip summaries, or planner wording
- shaping neighborhood, restaurant, or activity narratives

## Mission
Write like a guide, not a brochure.

## Core rules
- tone is cold, useful, and grounded
- highlight vibe, rhythm, and local fit
- budget users should get realistic local options, not tourist traps
- content must remain compatible with logistics-first pricing

## File focus
- `src/components/TripGuide.tsx`
- `src/TravelForm.tsx`
- `src/hooks/useRouteSearch.ts`

## Output standard
- useful narrative
- no hype language
- recommendations consistent with budget and transport reality
