## Backend audit — what changed in `/Users/vaimar/src/apps/slumber`

### New models added to `AntiCauchemarAnalysis`

| Field | Type | Description |
|---|---|---|
| `auditedTotalCost` | `number` | `realCost + hiddenCostPenalty + lateArrivalMarkup` — the only fully transparent out-of-pocket cost |
| `priceBreakdown` | `PriceBreakdown` | Structured stack of `CostLine` items ready to render |
| `manualCheckRequired` | `boolean` | True when transfer fee or arrival time cannot be validated automatically |
| `manualCheckReasons` | `string[]` | Explains why manual check is needed |
| `localAccessKnowledgeOverrideApplied` | `boolean` | True when 24/7 transport known for that airport |
| `localAccessKnowledgeNote` | `string \| null` | Human-readable note about local transport reality |
| `firstMileAccess` | `FirstMileAccess` | Home → departure airport context (user-supplied or estimated) |
| `doorToTripPrice` | `number \| null` | `auditedTotalCost + firstMileAccess.amount`. Null unless `firstMileAccess` was supplied. |

### New model: `PriceBreakdown`

```
PriceBreakdown {
  baseFare          CostLine   ← always EXACT (provider price)
  shuttleFee        CostLine   ← ESTIMATED or MANUAL_CHECK_REQUIRED
  baggageEstimate   CostLine   ← ESTIMATED
  lateArrivalMarkup CostLine   ← EXACT | ESTIMATED | OVERRIDDEN_BY_LOCAL_ACCESS_KNOWLEDGE
  firstMileLine     CostLine   ← present only when firstMileAccess supplied
  renderMode        "PRICE_TRANSPARENCY_STACK"
}
```

### New model: `CostLine`

```
CostLine {
  amount   number | null   ← null when status = MANUAL_CHECK_REQUIRED
  currency string
  status   EXACT | ESTIMATED | MANUAL_CHECK_REQUIRED | OVERRIDDEN_BY_LOCAL_ACCESS_KNOWLEDGE
  note     string          ← human-readable explanation
}
```

### New model: `FirstMileAccess`

Flat query params on `/api/flights` and `/api/trips/suggestions`:
- `firstMileAmount` — EUR cost to reach departure airport
- `firstMileDurationMinutes`
- `firstMileMode` — walking | public_transport | taxi | rental_car | other
- `firstMileCurrency` (always normalised to EUR)
- `firstMileStatus` — USER_PROVIDED | ESTIMATED | UNAVAILABLE
- `firstMileSource`, `firstMileNote`

### New model: `FlightSearchResult`

Returned by `/api/flight-search/departures` and `/api/flight-search/routes`. 
Fields: `flightNumber`, `airline`, `departureAirport`, `arrivalAirport`, `scheduledDeparture`, `scheduledArrival`, `flightStatus`, `estimatedTicketPrice`, `antiCauchemar`.

### New endpoints

| Endpoint | Description |
|---|---|
| `GET /api/flight-search/departures?iata=DUB&provider=serpapi` | Live departures via SerpApi / AviationStack / Kiwi fallback chain |
| `GET /api/flight-search/routes?from=DUB&to=BCN&provider=serpapi` | Live route search |
| `GET /api/hotels/{xid}/enrichment` | SerpApi-backed review/price enrichment for a single OpenTripMap place |
| `GET /api/ai/providers` | Returns readiness flags for openai / grok / gemini |

### Backend transfer estimator

`AntiCauchemarService.java` now uses:
1. **Nominatim geocoding** (OpenStreetMap) to look up airport + city-centre coordinates
2. **OSRM routing** (`router.project-osrm.org`) to get real road distance + time
3. Rate formula: `2.0 + (distanceKm × 0.28)`, capped at €25
4. Live results cached with configurable TTL (default: several hours)
5. Falls back to hardcoded `TRANSFER_PROFILES` map when live lookup fails
6. `LATE_TAXI_EUR = 60.0` — still used for nocturnal arrival warnings (override with `LOCAL_ACCESS_KNOWLEDGE` for 24/7 airports)

## Price hierarchy — canonical decision tree

```
1. backend.auditedTotalCost     → use as estimatedEntryPrice (includes lateArrivalMarkup)
2. recompute from flat fields    → ticketPrice + shuttle + bag (fallback)
3. doorToTripPrice              → additive only, never replaces realWorldEntryPrice
```

**Display order in hero card:**
```
Flight fare
€35.54              ← big, white: the Ryanair fare
Honest total: €59   ← sky blue: auditedTotalCost or recomputed
Door-to-trip: €69   ← indigo: only when firstMileAccess supplied
⚠ Manual check      ← red badge: only when backend can't validate
```
